# 忍者タイプ診断

全10問の質問に答えると、12種類の忍者タイプ(虚無僧・出家・山伏・商人・放下師・猿楽師・常の形・刺客・間者・武士・薬屋・薬師)のうち、最もスコアの高いタイプが診断結果カードとして表示されるWebアプリです。

詳細な設計方針は [CLAUDE.md](./CLAUDE.md) を参照してください。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 技術スタック

- React + Vite
- Framer Motion(結果画面の演出)
- 素のCSS(トークンベースの独自デザインシステム)
