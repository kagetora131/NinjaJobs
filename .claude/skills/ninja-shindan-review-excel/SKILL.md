# 忍者タイプ診断アプリ — 確認用Excel一覧(質問とポイント)の運用

ユーザーの要望(2026/9/20):**質問文・点数・移動定住の区分を変更するたびに、確認用の
Excel一覧を最新の内容に更新してから報告する**(違和感がないかを人が確認するため)。

- 生成:`npm i --no-save exceljs && node scripts/build-review-xlsx.mjs`
  (exceljsは実行時だけ入れる。`scripts/optimize-characters.mjs`と同じ流儀で、アプリの
  依存には入れない)。出力はプロジェクト直下の`忍者診断_質問とポイント一覧.xlsx`
  (git管理外。データは`questions.js`・`ninjaTypes.js`・`scoring.js`から直接作るので
  実装と一致する)。
- シート:1_仕組みの説明／2_共通7問(分類点・社交性・寡黙さ・移動定住区分)／
  3〜5_分岐(武家系・寺社系・庶民)／6_職業と区分(現在の出現率)／7_出現率の推移。
  各シート右端に「違和感(○/△/×)」「確認メモ」欄がある。ユーザーはここに、気になる点や
  「こう直したい」という値を書き込む。
- ユーザーの入力が入ったファイルを上書きしないよう、既存ファイルに入力があれば
  `…_入力済み_日時.xlsx`として別名で残してから再生成する。**入力済みのファイルは
  プロジェクトフォルダ以外(`C:\dev\Homepage\`直下)に保存されていたことがある**
  (2026/9/20)ため、入力を読むときは同名ファイルを検索して、更新日時の新しいものを確認する。
- 出現率の推移(7シート):ロジックを変える**直前**に
  `node scripts/build-review-xlsx.mjs --snapshot "ラベル"`で、その時点の値を
  `scripts/review-xlsx-history.json`に履歴として残す。
- 作業の順序:①変更前にsnapshot ②変更・総当たり検証・ブラウザ確認 ③Excel再生成
  ④CLAUDE.md(または`ninja-shindan-question-design` skill)更新 ⑤報告(更新したExcelの
  場所も伝える)。点数や区分を動かす提案は、対象の質問文・選択肢の全文と点数を並べて
  見せ、承認を得てから実装する。
